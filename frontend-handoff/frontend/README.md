# Sport Center

React + Vite + Bootstrap 5 + React Router DOM.

## Chạy dự án
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # build production
```

## Trang
| Đường dẫn | Trang |
|---|---|
| `/` | Trang chủ |
| `/bo-mon` | Bộ môn |
| `/lich-tap` | Lịch tập |
| `/huan-luyen-vien` | Huấn luyện viên |
| `/co-so-vat-chat` | Cơ sở vật chất |
| `/tuyen-sinh` | Tuyển sinh |

Nội dung chỉnh trong `src/data/content.js`, giao diện trong `src/styles.css`, ảnh đặt ở `public/images/`.
